## 📌 项目简介

本项目模拟炼化/石化**精馏塔**工艺场景，聚焦于**时序数据预处理**——特别是"截取策略"这一软测量建模中的核心环节。

通过对比**时延对齐 / 固定窗口 / 事件驱动**三种时序截取策略，验证了预处理方式对随机森林纯度预测模型的关键影响。

**一句话：** 用温度和流量数据预测产品纯度，解决化工时序数据"怎么截"的问题。

## ⚙️ 预处理管线

```
原始多变量时序 (F, T_top, L, B, Purity)
    │
    ├── 1. 缺失值插补（线性插值，模拟 2% 随机缺失 + 连续缺失块）
    ├── 2. 互相关时延估计（各变量到纯度的最优时延）
    ├── 3. 时序截取 ← ⭐ 核心亮点
    │      ├── 时延对齐截取（推荐：因果对齐，物理可解释）
    │      ├── 固定窗口截取（基线对比：忽略时延差异）
    │      └── 事件驱动截取（聚焦工况过渡过程）
    ├── 4. 滑动平均滤波（窗口=5步，抑制高频噪声）
    └── 5. 特征提取（均值/标准差/最小值/最大值/斜率/极差）
```

## 📊 结果

| 模型 | R² | RMSE |
|------|:--:|:----:|
| RF + 时延对齐 | ~77% | ~2.0% |
| RF + 固定窗口 | ~78% | ~2.0% |
| 线性回归（基线） | ~86% | ~1.6% |

> **结论：** 时延对齐在可解释性和物理一致性上优于固定窗口，  
> 特征重要性分析可直接指导工艺优化方向。

## 🧪 模拟数据说明

以**苯-甲苯精馏塔**为背景，基于**简化 Fenske 机理模型**生成，注入 5 类真实工业问题：

| 问题 | 参数 | 工业来源 |
|------|------|---------|
| 高斯噪声 | σ≈0.8°C | 传感器热噪声 |
| 脉冲干扰 | 概率 0.5% | 电磁干扰 |

| 缺失值 | 2% 随机 + 连续块 | 仪表掉线 |
| 工况阶跃 | +40 kg/h | 负荷调整 |

## 💡 关键技术讨论

| 话题 | 结论 |
|------|------|
| **为什么选RF不是LSTM？** | 软测量样本量小（200-2000条），RF无需大量数据+可解释性+易部署 |
| **大规模数据怎么处理？** | Parquet列式存储 + 增量滑动窗口 + Dask分布式 |
| **数据很脏怎么办？** | Hampel滤波/卡死检测/漂移补偿/工况识别分模式处理 |
| **为什么做两个版本？** | Node.js快速验证方法论，Python是工业标准实现 |
